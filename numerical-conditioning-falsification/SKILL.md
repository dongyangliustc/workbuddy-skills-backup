# 病态条件数的证伪审计（Numerical Conditioning Falsification）

## 何时用

- 某参数轴（截断阶、角动量上限、基组大小）被"**条件数天花板**"卡住：`cond` 每升一档恶化 3–4 个数量级，结果非单调不收敛。
- 有人提出**廉价代数重整**（列均衡 / 尺度归一 / 换基 / 改名归一化方案）声称能解锁该轴。
- 需要在**立项做结构性改造（换传播器/换算法）之前**，用低成本实验回答："便宜的方案够不够？"

## 核心洞见

> **换基 ≠ 治病。** 若待测量是 `x = U·A⁻¹·(下游)` 的形式，则**任何对角相似变换** `A → D·A·E`（等价地对 `U` 做同构缩放）在**精确算术下对 `x` 严格中性**。它唯一能改变的是 (a) 库的硬守卫、(b) TSVD/截断阈值决策、(c) 浮点舍入。
> 因此"重整后 `cond` 下降"**不构成成功**——必须同时报告**最终可观测量**。
> 判别"内在近简并 vs 尺度伪影"的唯一可靠判据是**尺度不变条件数**：把列尺度除掉之后，`cond` 与 `min_sv/max_sv` 是否仍近零。

## 步骤

### 0. 口径忠实性自证（先做，否则后面全是幻觉）
用你的驱动**逐位复现**一条历史基线（同一 (参数, 能量) 的 `cond`/可观测量）。不一致就先修口径，别往下走。
```
# 例：与既有扫描 JSON 的同格逐位对照
assert abs(mine["cond"] - hist["cond"]) / hist["cond"] < 1e-9
```

### 1. 找到并区分"守卫"与"注入点"——**决定可达性**
最关键的、最常被忽略的一问：**你的重整作用在库守卫的哪一侧？**
- 若库在**对原始矩阵**施判（如 `cond(raw) > 1e12 ⇒ raise`）后才调用 `pinv`，则**任何作用在 `pinv` 层的重整在高档位都不可达**（守卫先炸）。
- 唯一可达的做法是让重整作用在**矩阵被构造之前**的输入上（作用在解 `u` / 载荷上）。
- 实现手段：进程内**运行时重绑模块全局名**（`module.func = wrapper`），零磁盘改动。Python 在调用点解析模块全局 ⇒ 可行；若 `cond` 与基线**逐位相同**，说明劫持未生效（作用域问题），须排查后重跑——**禁**把"未生效"当成"方案无效"。

### 2. 证明/验证相似不变性（把"换基"与"治病"分开）
解析写出不变性，再用数值验证到机器精度：
```
# P1: A_t = A·diag(1/c)  ⇒  pinv(A) = diag(1/c)·pinv(A_t)
# P2: u → u·diag(1/s)    ⇒  A → A·diag(1/s),  u_hat = u·A⁻¹ 不变
assert rel_change(observable) < 1e-12     # 在 cond 足够低的档位上
```
若不变性成立 ⇒ 该方案**不可能**改善收敛性（只能经截断/舍入间接影响）。这一步常常**直接终结讨论**，省掉整轮实验。

### 3. 尺度不变条件数判据（核心判别）
```
def eq_cond(M):                       # 列均衡后的条件数（尺度不变）
    c = np.linalg.norm(M, axis=0); c = np.where(c > 0, c, 1.0)
    return np.linalg.cond(M / c)
s = np.linalg.svd(M / c, compute_uv=False)
min_sv_over_max = s.min() / s.max()   # ≈1e-15 ⇒ 数值秩亏 ⇒ 内在近简并
```
- 均衡后 `eq_cond` 仍 ≫ 目标门限（且 `min_sv/max_sv` 趋 1e-15）⇒ **病态在矩阵的"形状"里，不在列尺度里** ⇒ 换基类方案**整类否证**。
- 同时看**孤立近零模 + 谱隙**签名，比裸 `cond` 更能区分"梯度病态"与"真近简并"。

### 4. 测"表示层"是否已近简并（决定是否需要换算法）
把同一个尺度不变判据施加到**基本解/基函数矩阵本身**（不只施加到拟合出的振幅矩阵）：
```
eq_cond(u(r_match))     # 若随参数档增长到 1e9–1e10 ⇒ 表示层真近简并
```
- 若**基本解矩阵**本身近奇异 ⇒ 任何"必须分离这些解"的匹配流程（含振幅拟合）都被击穿 ⇒ 需要**换传播器**（对数导数 `Y=u'u⁻¹` / R-matrix）。
- 若 `Y` 的条件数明显优于 `u`（`Y=u'u⁻¹` 对右乘常数矩阵不变，故对"各列共有的污染分量"免疫）⇒ 结构路线**有可辩护的技术依据**（但这是**提示**，不是结论：`Y` 若由受污染的 `u` 反解，其条件数本身不可全信；须真正推进 `Y` 积分才能定论）。

### 4.1 ⭐ 天花板会**迁移**：追踪"状态 → 可观测量"链上**每一个**被求逆/求解的矩阵
换传播器后**不要**因为"新的积分器条件数很好"就宣布解锁。**天花板常常只是搬了家。**

判据是一条**链条审计**：列出从状态到可观测量之间**所有**必须求逆或求解的矩阵，逐个测其尺度不变条件数：

```
传播层 :  cond_eq(Y)                       # 换传播器后应有界（常常确实有界）
振幅层 :  cond_eq(A_reg)  或  cond_eq(C_fit) # ← 天花板通常搬到这里
守卫层 :  库在哪个 cond 上硬抛
```

- 实测规律：**传播层有界 ≠ 解锁**。若最终仍须把逐通道振幅从解基 `U` 中分离（无论写成 `A_reg = UF − U'G` 的求逆，还是写成高矩阵最小二乘拟合 `C`），该分离步骤**继承同一近简并**，只是换了矩阵名。
- 因此"某重整/换算法能解锁"的可辩护形式是：**链条上最后一个被求逆矩阵的条件数**随目标档位保持有界，且**最终可观测量与基线在该档位一致**（双证据，缺一不可）。
- 报告用语：**"近简并是解基的列空间属性，不是某个求逆算法的属性"** ——这句话比"方案 X 失败了"有力得多，也界定了否证范围（整类振幅分离路线，而非某一个实现）。
- 定位**崩点**：把"目标档"之外的中间档也扫出来，找到"最后可用档"和它的 `cond_eq` 量级（例：`cond_eq(C_fit) ≲ 1e4–1e5` 可用、`≳1e5` 崩），这给出**可操作的可用性门限**。

### 4.2 与库对照时：对数导数矩阵/带极点量必须用**范数比**，且门只施加在"喂给可观测量的那个半径"上
若库把同一量用**有限差分**（如 5 点 O(h⁴)）算出来，则 `Y=u'u⁻¹` 在**波函数节点处有极点**：
- 逐元相对误差 `|ΔY|/|Y|` 在节点邻域被（双方共享的）极点主导 ⇒ **无意义**，会伪造出 1e2–1e3 的"误差"。改用 **Frobenius 范数比** `‖ΔY‖/‖Y‖`。
- 库自己的差分分辨地板会高于 ODE 精度（实测 1e-5 量级）；把**远场分布**（median/p95/p99/max/超阈值点数）与**门半径处的值**分开报告。
- **门只施加在 `r_match`**（唯一喂给下游提取的半径）；远场尾部作为**残余不确定性**申报，并用**独立积分器**（如 RK4）当裁判来定性尾部归谁。
- 若 `ΔY` 与步长**无关**（加密不收敛）⇒ 先怀疑**公式/假设错**，而不是精度不够。

### 5. 沿自变量剖面（定位根因，而非推断）
```
for r in [r1, r2, r3, ...]: profile[r] = eq_cond(u(r))
```
- 只在远场爆炸 ⇒ 疑似长程污染 / 增长解污染；
- **在内部就已爆炸** ⇒ 表示层通道集近简并（与"窗长"无关）。
用这一段把"根因"从**推断**变成**实测**——台账/报告需要的是实测。

### 6. 报告纪律
- **必须同时**报告 `cond`（重整后）**与**最终可观测量；只有 `cond` 下降不成其为成功。
- 报告"可达性"结论（方案能否越过守卫、是否边际可达）。
- 显式声明**未完成项**与理由；不伪造未验证的结论。
- 高成本方案（换传播器）若时间盒不够，只交付**前提检验**并明确标注。

## 陷阱清单

| 陷阱 | 症状 | 处理 |
|---|---|---|
| **换基冒充治病** | `cond` 降了 2–3 个数量级就宣布成功 | 同时看可观测量；用不变性证明判死刑 |
| **守卫在重整之前** | 高档位仍 raise，误以为"方案无效" | 先定位守卫；把重整移到守卫之前（作用在输入上） |
| **raw 逆在 cond≳1e10 已是噪声** | 同格三种"等价"方案互相差 ~15% | 该区间结论不可作判据；标记为噪声主导 |
| **劫持未生效当成方案无效** | `cond` 与基线**逐位相同** | 加调用计数器；`pinv_calls/numerov_calls > 0` 才算生效 |
| **只看远场列范数比** | 误把 `cond` 归因于列尺度 | 列尺度最多贡献"列范数比"那 1–2 个数量级；剩余必须在**均衡后**再测 |
| **判据前提已破** | 要求"高档 vs 低档 <5%"，但低档之间本就差几十倍 | 先验证判据在**基线可用档内**成立；否则先改判据 |
| **`n_pos`/符号类判据在病态点失效** | 结果自相矛盾 | cond 过大时不作判据（K-AS 纪律：主判据须自带良态性） |
| **换传播器后只看传播层就宣布解锁** | `cond_eq(Y)` 很好，但 σ 在高档位大 10^3–10^4 倍 | **链条审计**（§4.1）：逐个测到可观测量之间所有被求逆/求解的矩阵 |
| **矩阵函数步静默对称化** | 与库差一个**与步长无关**的常数倍（如 550%） | 若库接受非对称矩阵，你的 `cos/sin(√M)` 等**必须用整函数**（Taylor+缩放倍增），**禁** `0.5(A+Aᵀ)` |
| **文档声称对称、代码非对称** | 文档说"只某分量贡献 ⇒ 对称"，实测 `max\|V−Vᵀ\| ≠ 0` | 实测矩阵对称性，勿信 docstring（同类"文档↔代码漂移"）；非对称不可怕，静默假设对称才可怕 |
| **步长无关的误差当成精度不足** | 加密步长不收敛 | 步长无关 ⇒ 公式/假设错（对称化、错因子、错边界）；先查公式 |
