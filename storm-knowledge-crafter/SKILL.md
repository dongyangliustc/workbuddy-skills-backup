# 风暴知识工坊 (Storm Knowledge Crafter)

> 基于 `source-grounded-mcp` 升级而来，融合大刘的10步闭环学习法 + 斯坦福STORM多视角研究法（NAACL顶会论文）。
>
> 核心设计理念：**真正的学习需要四个要素——一条路径、一次测试、一次压缩、一个反馈循环。**

## 能力概述

本技能提供两大核心能力层：

### 层一：资料索引引擎（继承 source-grounded-mcp）
将本地 PDF/TXT/Markdown 资料转化为可检索的只读 MCP 知识库，提供证据可追溯的问答能力。**这是所有学习活动的证据基础设施。**

### 层二：10步风暴学习法
基于大刘（AI大刘，北大毕业，腾讯/百度大模型研发）的完整闭环学习方法论，覆盖从**入门 → 深化 → 记忆 → 回顾**的全流程。每步附带可直接使用的提示词模板。

---

## 工作流总览

本技能有两种启动路径，根据用户需求选择：

### 路径 A：已有资料 → 先建立索引，再用10步法学习
完整流程。适合拥有 PDF/TXT/MD 资料的场景，先建立 MCP 知识库，再执行学习闭环。

### 路径 B：无资料 → 直接用10步法学习
跳过阶段一，直接启动学习闭环。适合对纯知识领域进行泛学习。

## 阶段一：资料准备与索引

**仅在用户有本地资料文件时执行此阶段。**

### 步骤 1.1 — 扫描资料清单
运行 `scripts/create_source_manifest.py MATERIALS --output INVENTORY.json`。

扫描仅包含 selectable-text PDF、TXT 和 Markdown 文件，不含权威字段。

### 步骤 1.2 — 确认来源分类
如果用户尚未对所有来源进行分类，展示 confirmation table。包含：文件路径、显示标题、建议来源类型、建议优先级、文字提取可行性。
**Do not ask the user to edit JSON or YAML.** 如果用户已提供明确的分类策略，以备注形式说明建议表格，然后继续。

### 步骤 1.3 — 搭建 MCP 项目框架
运行 `scripts/scaffold_course_mcp.py PROJECT`。拒绝覆盖非空目录。

### 步骤 1.4 — 写入来源配置
阅读 `references/evidence-contract.md`。根据确认表格写入 `PROJECT/config/sources.yaml`。使用绝对 `source_root`、清单中的路径/格式、稳定的唯一 ID、确认的标题/类型、整数优先级。不留占位符。

### 步骤 1.5 — 构建索引并验证
从 `PROJECT` 目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m pytest -v
.venv/bin/course-material-mcp ingest
.venv/bin/course-material-mcp search "代表性查询"
```

如果有来源无法提取文字，停下来报告，可能需要 OCR 或转换。

### 步骤 1.6 — 注册 MCP 服务器
```bash
codex mcp add MCP_NAME -- ABSOLUTE_PROJECT/.venv/bin/course-material-mcp serve --config ABSOLUTE_PROJECT/config/sources.yaml --index ABSOLUTE_PROJECT/data/index/materials.sqlite
codex mcp get MCP_NAME
```

如果名称已存在，请求用户许可后替换。

### 步骤 1.7 — 告知用户
通知用户重启 WorkBuddy 或打开新任务。给出测试提示词，要求返回 `[资料事实]`、精确定位符、`[模型推理]`、`[资料不足]`。

## 阶段二：10步风暴学习法

> 此阶段在索引建立完成后（或用户选择无资料直接学习时）执行。
>
> 每个步骤给出可直接使用的提示词模板。用 `【主题】` 标记需替换的内容。

### 第1步 · 五视角 STORM 拆解

让 AI 模拟 5 位完全不同的专家视角，从根本不同的角度拆解同一主题。

**何时使用**：刚接触一个陌生领域，需要快速建立全景认知。

**提示词模板**：

```
我要研究【主题】。

请模拟 5 位不同的专家，从各自的视角分析这个主题：

1. 实践者：每天跟这东西打交道的人。
   他们知道哪些学者不知道的事？哪些实际情况总是被忽略？

2. 学者：研究这个领域多年的人。
   同行评审的证据到底说了什么？证据在哪些地方和大众认知相反？

3. 怀疑者：认为主流观点有问题的人。
   最强的反方论点是什么？支持者们刻意忽略了哪些证据？

4. 经济学家：盯着钱流向的人。
   谁在从当前的叙事里获利？哪些利益在影响这个领域的结论？

5. 历史学家：见过类似规律的人。
   历史上有什么相似的先例？那些先例最后是怎么收场的？

每个视角请给我：
- 两句话说清他的核心立场
- 支持他观点的最强证据
- 一件只有他会告诉我、其他视角绝不会提的事
```

**预期产出**：五份相互独立的、可能存在冲突的深度解读。

---

### 第2步 · 矛盾图谱

让五个视角互相质疑，找出认知深水区。

**何时使用**：拿到五视角结果后。这一步骤是浅调研和深调研的分水岭。

**提示词模板**：

```
基于上面 5 个视角，给我画一张矛盾图：

- 哪些视角在直接冲突，各自的依据是什么；
- 谁的证据最强、谁的最弱、为什么；
- 哪一个问题一旦有答案，就能化解最大的矛盾；
- 所有视角都同意的是什么（这大概率是真的）；
- 没有任何视角提到的是什么（这可能是整个领域的盲区）。
```

**预期产出**：
- ✅ **共识清单** — 连对手都承认的事，可以放心用
- 🚩 **盲区清单** — 所有视角都没提的东西，可能是最大的发现

---

### 第3步 · 综合简报

将前两步的成果压缩成一份可用的简报。

**何时使用**：有了多视角素材和矛盾分析后，收拢为结构化报告。

**提示词模板**：

```
把 5 个视角和矛盾图综合成一份调研简报：

- 一段话总结（讲给只有 60 秒的 CEO 听，要细节，不要标题党）；
- 5 个关键发现，按可靠性排序，标注哪些视角支持、哪些反对；
- 一个只有把 5 个视角放在一起才能看到的隐藏关联；
- 一条具体的行动建议（以我的角色，我该做什么不一样的事）；
- 一个前沿问题（它的答案会改变我们对这个主题的全部理解）。
```

---

### 第4步 · 同行评审自检

让 AI 给前面的简报挑刺。STORM 论文承认的已知短板：缺乏自我批判机制。

**何时使用**：简报完成后，在进入资源收集前。

**提示词模板**：

```
现在请你对刚才这份简报做一次同行评审：

- 给 5 个关键发现逐个打 1-10 的可靠性分，并解释理由；
- 你最没把握的是哪个结论，需要什么信息才能验证它；
- 哪个视角在综合时占的比重过大了；
- 有没有第 6 个视角是该加进来、加了会改变结论的；
- 如果一位斯坦福教授来评审这份简报，会打几分，会让我改什么。
```

---

### 第5步 · 资源筛选

**解决"收集、整理、吃灰"问题**——让 AI 做策展人，只留最精华的 5 个资源。

**何时使用**：需要深入学习了，但资料太多不知道从何看起。

**提示词模板**：

```
关于【主题】的资源太多了，我不想再收藏了。

请你当一个只帮我省时间的策展人：

- 选出 5 个最值得用的资源（书、视频、课程、社区都行），
- 每个说清楚：它为什么比同类强、该怎么用（读/看/练）、
- 大概要花多久、我该从它身上拿走的一个关键点；
- 再告诉我哪些是被高估的、我该躲开的坑；
- 最后把这 5 个排成一条一周能走完的学习路径。
```

---

### 第6步 · 学习阶梯

基于维果茨基"最近发展区"理论，将主题分解为 5 个清晰难度级别。

**何时使用**：确定了学习资源后，规划分阶段的学习路线。

**提示词模板**：

```
我想一步一步地学习【主题】，不跳过任何重要的基础。

请你扮演一位专家教师和技能教练，把【主题】分解为 5 个
清晰的难度级别，从完全初学者到自信的实践者。

每个级别包括：
1. 级别名称
2. 这个阶段我应该理解什么
3. 在这个级别上"掌握"是什么样子
4. 最需要重点关注的概念或技能
5. 一个证明我可以进入下一级别的里程碑
6. 一个动手练习或小型项目
7. 这个级别的学习者常犯的错误
8. 进入下一级别前的一个简单自测问题

按这个结构组织级别：
- 级别 1：完全初学者
- 级别 2：基本理解
- 级别 3：实际使用者
- 级别 4：问题解决者
- 级别 5：自信的实践者

解释保持实用、对初学者友好，专注于真正的进步。
```

---

### 第7步 · 2小时啃下核心20%

帕累托法则的应用——用最短时间锁定能撬动 80% 效果的 20% 核心知识。

**何时使用**：学习路径已定，需要快速"先上手干活"。

**提示词模板**：

```
我想用 2 个小时学【主题】。

请先找出能带来 80% 实际效果的那 20% 的概念和技能，
解释它们为什么是核心；

然后排成 10 次课的学习计划，每次课包含：
- 学习目标
- 关键概念
- 一个动手练习
- 一个推荐资源（最好免费）
- 完成后的预期结果

每次课结束，给我 5 个复习题。
全部结束后，给我一个能证明我真的可以上手用的最终小项目。
```

---

### 第8步 · 考到我崩溃

基于认知心理学"测试效应"（retrieval practice）——从脑子里往外掏知识，比往脑子里塞知识更能让知识记住。

**何时使用**：感觉自己"懂了"但不确定是真懂还是假懂。

**提示词模板**：

```
我刚学完【主题】，想测试自己到底理解了多少。

请你扮演一位严格但乐于助人的考官，
通过主动回忆找出我理解的边界。

从 10 个问题开始，一次只问一个。

规则：
1. 问题逐渐变难：第 1-3 题初级，第 4-6 题中级，
   第 7-8 题高级，第 9-10 题专家级。
2. 一次只问一个问题，等我回答。
3. 每个回答之后，做四件事：
   - 给我的答案打 0 到 10 分
   - 告诉我哪里答对了
   - 指出确切的差距、错误或薄弱点
   - 用简单的语言重新解释我漏掉的部分
4. 如果我答得很弱，先追问一个问题，再进入下一题。
5. 如果我答得很好，稍微增加难度。
6. 最后给我：最终得分、我最强的领域、我最弱的领域、
   一个简短的复习计划、5 个最终挑战题。

不要一次给我所有答案。让这像一场真实的学习面试。
```

---

### 第9步 · 费曼循环

费曼技巧的四步闭环：学习 → 教授 → 回顾 → 简化。

**何时使用**：被考出知识薄弱点后，用费曼法补窟窿。

**提示词模板**：

```
我想用费曼学习法吃透【概念】。

请你当一个有耐心的学习伙伴：

1. 先用简单的词、生活里的例子把它讲给我听，就当我 12 岁；
2. 然后让我用自己的话复述一遍；
3. 接着找出我复述里每一个含糊、跳步、绕不过去的地方，
   只重新教这些部分；
4. 再让我讲一遍。循环下去，
   直到我的解释简单、准确、完整。

在我讲清楚之前，别进入新内容。
```

---

### 第10步 · 一页速查表

学完的知识压缩成单页高效参考——"面试前、开会前、要给别人讲之前，花 5 分钟扫一遍"。

**何时使用**：全部学习流程走完后，产出最终交付物。

**提示词模板**：

```
给我做一份关于【主题】的一页速查表，
让我在要用它之前，花 5 分钟就能过完：

- 一句大白话定义；
- 最重要的概念、规则、公式或步骤，全用短条目，别用长段落；
- 3-5 个真实场景的例子；
- 新手最容易犯的错、最容易混淆的地方；
- 一份"上场前"检查清单；
- 最后加 5 个快问快答，测测我还记得多少。
```

## 完整学习闭环

以上 10 步构成一条完整的学习流水线：

```
陌生领域 → 五视角拆解 → 矛盾图谱 → 综合简报 → 同行评审
     ↓
5个精选资源 → 学习阶梯 → 2小时核心20%
     ↓
主动回忆测试 → 费曼循环补漏 → 速查表产出
```

### 迭代建议

- **首次跑完**：获得一个主题的"全景图 + 行动路线"
- **需要复习**：重跑第 8 步（测试）+ 第 10 步（速查表）
- **深入研究**：重跑第 1-4 步（五视角视角可以换一批专家）
- **有新资料**：更新 MCP 索引后，重跑第 8-10 步

---

## 验收标准

### 资料索引层
- MCP 仅暴露 `search_sources`、`read_source_segment`、`list_source_policy` 三个工具
- 返回 title、type、priority、exact locator、bounded excerpt、retrieval score
- 高优先级来源优先匹配
- 绝不暴露任意文件系统、shell、写入或模型密钥工具

### 学习闭环层
- 每个步骤完成后形成可交付的中间成果（简报 / 路径 / 测试结果 / 速查表）
- 第 8 步测试结果需标注强弱项分布
- 第 10 步速查表需能在 5 分钟内扫完
- 操作者应能明确感知自己的理解深度在逐步递进
