# 风暴学习法协议 (STORM Learning Protocol)

> 本协议文档基于大刘（AI大刘）的10步闭环学习方法论，融合斯坦福STORM多视角研究法（NAACL 2024）。
> 原文出处：大刘微信公众号文章《用 Claude/Codex/Workbuddy 10倍速学习任何知识（附完整方法）》
> 方法论来源：@sairahul1 (Rahul) + Stanford STORM paper

## 核心理论基础

### 1. 学习四要素（Rahul）
真正的学习需要四个要素：
- **一条路径** — 清晰的学习路线图
- **一次测试** — 验证理解深度的机制
- **一次压缩** — 将知识压缩为可快速调用的形式
- **一个反馈循环** — 闭环纠偏机制

### 2. STORM 多视角方法（Stanford）
一个领域真正的样子，不长在大多数人的观点里，而是长在五种人眼中不同的东西：
- 实践者 — 知道学术界不知道的实际细节
- 学者 — 掌握同行评审的实证证据
- 怀疑者 — 看清主流叙事的盲区
- 经济学家 — 追踪利益流向和激励机制
- 历史学家 — 识别历史规律和先例

这些视角的差异，才是学习的核心。

### 3. 测试效应（Retrieval Practice）
从脑子里往外掏知识这个动作本身，比往脑子里塞知识，更能让知识记住。

### 4. 最近发展区（维果茨基）
一个人能学会的东西，永远长在"他已经会的"旁边一小步——踮踮脚能够着的东西才学得会。

## 使用原则

### 顺序不可逆
前4步是认知基建（全景→矛盾→简报→自检），中间3步是学习规划（资源→阶梯→核心），后3步是深度吸收（测试→费曼→压缩）。跳级学习是最大的效率杀手。

### 迭代优于完美
首次跑完10步获得"初版认知"，后续可针对薄弱环节重复特定步骤。第8步（测试）可反复使用。

### 证据基础优先
如果已有本地资料（PDF/书籍/文档），务必先执行"阶段一：资料准备与索引"，让每个学习步骤都能追溯回原始资料。资料不足时标注 `[资料不足]`。

## 与 MCP 证据系统的集成

当资料索引已建立（阶段一完成后），所有学习步骤应优先使用 MCP 知识库作为证据源：

- 第1步五视角 → 使用 `search_sources()` 检索各视角的证据原文
- 第5步资源筛选 → 优先筛选本地资料中的精华内容
- 第8步测试 → 使用 `read_source_segment()` 精确定位模糊概念
- 第10步速查表 → 使用 `search_sources()` 验证速查表的事实准确性
