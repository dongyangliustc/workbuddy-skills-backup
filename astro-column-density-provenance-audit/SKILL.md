# 观测柱密度溯源审计（μ / Q 的出处与传播）

## 何时用

- 要把观测论文的**柱密度、丰度比、链长趋势**作为自己理论工作的经验锚点，需要先确认这个锚点有多硬。
- 怀疑某篇观测论文的比值里**混入了不同年代的物理常数**（最典型：自由基 μ 被后来的多参考计算大幅修正）。
- 需要在稿件里写一句**可被审稿人接受**的观测端系统误差说明。

**不适用**：纯粹的文献检索（用文献类 skill）；需要原始谱重新拟合（需 GOTHAM/DR4 等原始数据，本 skill 只做溯源与传播）。

## 核心公式（一切传播的出发点）

光学薄、同源、同波束、同一 T_ex 下：

```
N ∝ Q(T_ex) / [ μ² · S · f(J, T_ex) ]
```

因此两个物种的比值：

```
R = N_A/N_B ∝ [Q_A/Q_B] × [ μ_B² / μ_A² ]        ← μ 不约掉
δR/R = 2·(δμ_B/μ_B) ⊕ 2·(δμ_A/μ_A)               ← 对数传播，注意 μ² 放大 2 倍
```

> 必记的口径：μ 偏 20% → 比值偏 ≈44%。所以 μ 是比值的**主导系统项**，而论文自报的 1σ 通常**只含拟合统计量**。

### ⚠ 相消性判据（在把任何偏差归因到 μ / Q 之前，先做这一步）

上式是**单源内**的物种比值，μ 不约掉。但一旦讨论的是**跨源**的"同一物种比值之差"，结论完全不同：

```
G ≡ R_X / R_Y = [N_X(anion)/N_X(neutral)] / [N_Y(anion)/N_Y(neutral)]
```

μ（以及 Q(T_ex)、线强 S、填充因子约定）是**与源无关**的乘性标定常数。若某常数由 c₀ 改为 c₁（k ≡ c₀/c₁），则**每一个**用它的源都满足 R → k·R，于是

```
G → (k·R_X)/(k·R_Y) = G          ← 严格相消
```

**⇒ 任何"同时作用于两源"的乘性标定误差在跨源比值之比中贡献恒为 0。** 由此得到两条硬推论：

1. **不存在任何"系统性标定假象"能制造或抹掉跨源差距**——μ 修订既不能产生 G，也不能消掉 G。**把跨源 20× 说成"μ 制造的口径假象"是错的，会被立刻驳回。**
2. G 只可能来源于 **(i) 两源真实物理差异**（密度、温度、UV 场、几何）或 **(ii) 非对称的代次处理**（只有一个源被重分析过）。

**操作口诀**：先问"这个常数是**两源都有**还是**只在一个源里**？"——两源都有 ⇒ 相消，改换归因；只在一个源里（或只重算了一个源）⇒ 才会改变 G。

**易犯的混合代次错误**：拿"被重分析过的源"比"未被重分析的源"，得到的差 ≈ 1 或 ≈ 旧差距，**两者都无意义**。必须**统一 μ 口径后再比**（若只有一个源可更新，则给另一个源做同口径的 μ 换算）。

## 工作流

### 1. 穷举论文实际声明的 μ（负面证据同样重要）

```bash
# 对已抽取的全文做穷举，不要只搜 "dipole"
rg -n -i "dipole|Debye|moment|µa|mu =" <full_text.txt>
```

记录三件事：① 论文给出了几个 μ 数值；② 给出的是哪几个物种；③ **没有**给 μ 汇总表 / **没有**做传播——这两条负面结论本身就是审计结论。

### 2. 核对配分函数：Table = 目录原值？

射电论文的 Q 表通常直接抄目录。用 CDMS 官方条目逐位核对（URL 规律）：

```
https://cdms.astro.uni-koeln.de/cgi-bin/cdmsinfo?file=eNNNNNN.cat
```

条目页免费给出：电子态、**µa（Debye）及其文献出处、是否标注 estimated**、B、以及 Q(2.725 … 300 K) 全表。
若要确认目录**注释**（哪条阶梯未测、是否含超精细/振动激发），必须读条目正文——这是最有力的证据。

**刚性转子自检（必做）**：闭壳层 ¹Σ⁺ 线性分子的 Q 必须严格 ∝ T。取 Q(300)/Q(9.375)，应 ≈ 32.00。
- ≈32 → 物理总量；
- 明显 <32 → **目录能级求和被 J 上限截断**（该表在高 T 不可复用）；
- 明显 >32 → 目录含振动激发态（对 C_nH 系常见）。

### 3. 阶梯完整性审计（判断"整条电子态/自旋-轨道阶梯是否缺失"）

对同一（阴离子，自由基）对，取同一 T（**9.375 K**，SPCAT 标准温度）：

- 用闭壳层阴离子标定 f=1：Q(an) ≈ kT/(hB) → 反解 B，与实验室值对照（自洽性验证，误差应 <0.1%）。
- 自由基理论 f=4（细结构或阶梯重数 2 × 超精细 2I+1=2）。
- 实测 Q(rad)/Q(an) **减半**（≈2 vs ≈4）即提示目录缺一个**温度无关**的 ×2 权重。

> **陷阱**：自旋-轨道阶梯与 ¹H 超精细简并**都是温度无关的 ×2**，仅凭 Q 值不可区分。要定论必须读 `.cat` 原文或调取 cat 文件。**不要**在报告里把"缺半"直接断言为"缺自旋-轨道阶梯"。

**量级校验**：若怀疑的机制是"激发态布居被忽略"，用 f_up = 1/[1+exp(−ΔE/T_ex)] 换算——冷云 T_ex = 5 K、ΔE = 30 K 时 f_up ≈ 0.3%，**永远不构成系统性低估**。真正需要担心的是 μ。

### 4. 追溯 μ 的年代（本方法最常命中的问题）

对该分子家族，逐个建立 μ 表，列出**每一代取值 + 方法 + 是否实验**。注意：

- 该家族（如 C₂ₙH）的 μ **很可能全部是理论值、无一例实验测定**——这本身就是结论。
- 警惕**态混合**这一类修正：近简并的 ²Σ⁺/²Π 会使有效 μ 显著偏离孤立态值（C₄H：0.87 → 2.10 D，²Π 成分 ≈40%，N 修正 ×5.83）。这类修正**强烈依赖链长**（只有近简并的那一个成员受影响），因此会**改变丰度比 vs 链长的趋势形状**。
- 判定修正是否"纯 μ⁻²"：检查论文自述的修正因子是否等于 (μ_new/μ_old)²（C₄H：(2.10/0.87)² = 5.83 vs 原文 "factor of 6" ✓）。

### 5. 从附录表独立复算比值（不要抄正文比值）

各附录通常给出逐速度成分的 N_T 与 N_T(Total)。**自己相除**，并与论文引用的文献值对比：

```
measured/cited 的偏离  ÷  μ 修正因子  ÷  同族"无 μ 修正"成员的方法学偏移  =  残差
```

第三步是关键技巧：若同族的其它成员**不涉及 μ 修正**却同样偏离 ~2×，那 ~2× 应归为**方法学/环境差异**（不同巡天、MCMC vs 转动温度图、速度成分数不同），可用来"标定"并剥离，避免把方法学误差误算成 μ 误差。

### 6. 输出

产出一份 md，固定包含：
1. **结论摘要表**（判定 + 依据）；
2. **原文穷举**（含负面证据）；
3. **μ 完整出处表**（数值 / 方法 / 性质：实验 or 计算 / 备注）；
4. **传播计算**（列公式、列基准、列敏感性表：换用不同已发表 μ 组后 R 的取值）；
5. **与论文自报不确定度的对比**（μ 系统 vs −1σ：**若 μ 系统 > 下界 1σ，明确写出"自报区间未覆盖 μ 系统项"**）；
6. **建议写入稿件的英文措辞**；
7. **交接表**：已关闭 / 部分关闭 / 新登记的待核项与风险。

并把所有数值写进一个可重跑的脚本（输入全部为"原文引用值 + 出处注释"），避免手算。

### 7. 争议探测审计（当锚点被后续文献挑战时）

若该柱密度/比值已被**后续文献公开质疑**（常见于"叠线堆叠法探测"这类弱信号），必须再走一遍。**目标不是判谁对，而是判自己的稿件还能不能引用它。**

**(a) 先拆层次。** 把争议拆成三层，因为它们对稿件的影响完全不同：
1. **探测是否为真**（最致命，一旦为假则比值无意义）；
2. **数值偏多少**（可加注区间处理）；
3. **该比值的含义**（趋势支点是否可用）。
> 只做 (2) 的加注、而没意识到 (1) 被质疑，是这类任务最常见的失误。

**(a2) ★ 先查"被质疑方自己是否已经改口"。** 这是本方法**性价比最高的一步**，常常一步结案：
在细究双方论据之前，先检索**被质疑团队在争议年份之后是否发表过"统一重分析 / 全样本库存"类论文**（典型形式：
"Molecular inventory of X with <survey> observations"、同管线重跑全部物种的贝叶斯/MCMC 汇算）。这类论文会用**统一
口径**重算所有物种，包括争议物种——若它给出的值与争议方的主张量级一致，则"争议"其实**已在团队内部解决**，
可直接采用新值，不必再逐条驳论。
- 实例：C₁₀H⁻ 争议中，被质疑方（GOTHAM）自己的 **Xue et al. 2025, ApJS 281, 9** 把 N(C₁₀H⁻) 从 4.04 × 10¹¹
  降到 **1.8 × 10¹⁰（降 ~22×）**，与挑战方主张的"20–30×"同量级 ⇒ 争议主体已闭合。
- **交叉自洽检查**（防该论文自身有问题）：把该重分析中**其余同族物种**的值与独立多线定值（如 Agúndez et al. 2023）
  对比；若全部落在 ~25% 内，则其争议物种的新值可信。（本例：6 个阴离子全部与独立定值互洽。）
- ⚠️ 注意区分**同团队不同数据释放**（DR4 vs DRV、单目标探测论文 vs 全样本汇算）——下调往往来自口径变化，
  不是"认错"。报告里应写清是哪一层变化。

**(a3) 先给整个分子家族做"证据分档"，再定位争议在哪一档。** 别默认"整个系列都有问题"。用**两个正交判据**把家族成员分档：
- **判据 ①：是否有实验室转动常数**（不是从头算）；
- **判据 ②：是否有逐线确认**（多条独立谱线构成的谐波系列）。
只有**同时缺 ①②**的成员才会被质疑"探测真伪"；缺 ① 但有 ② 的成员通常被接受（但须注明无实验室锚点）；
①②兼备的成员证据链从未被质疑，可作为硬锚点。产出成表，格式：`物种 | 首次探测 | 实验室常数 | 逐线证据 | 争议状态`。
- ⚠️ **自指陷阱**：若被质疑物种的 **B 是从待检验数据自身反解出来的**（而非独立给定），则"速度是否正确"这一判据与 B 完全耦合，
  构成 look-elsewhere 结构。这是全家族通常唯一的自指实例，也是最脆弱的一点。
- ⚠️ **频段错配诊断（常被忽略，且可复算）**：线性分子 **B ∝ 1/(链长)²**，故链越长 LTE 发射峰越向低频移。
  先算 **J_peak ≈ √(kT/2hcB)** 与峰值频率 **2B·J_peak**，再算**巡天波段内最低 J 的 E_up = B·J(J+1)/(k/h)**（k/h = 20.836 GHz/K）。
  若峰值远在波段之外、且波段内最低 J 的 E_up ≫ T_kin，则"看不到"是**仪器性失明**，不是"不存在"——此时低灵敏度的堆叠法反而
  成为唯一通道，争议随之而生。**源温度也决定证据强度**：同一分子在暖源（T ≳ 100 K）中高 J 线被充分激发、可得数十条单线；
  在冷源（T ≈ 10 K）中同样跃迁被 Boltzmann 压制（e^(−E_up/T) 可达 ~10⁻²）⇒ **暖源的线数不能用来支持冷源的探测**。
  实例：C₁₀H⁻ 在 TMC-1（10 K）Q 波段最低 J = 52、E_up ≈ 40 K，故 QUIJOTE Q 波段结构性失明；而在 IRC+10216（~300 K）同一 J 区间给出 15 条单线。

**(b) 找挑战方论据中"载重"的那一条。** 逐条问：该论据是否**独立于**其它论据？典型陷阱是"源尺寸—柱密度协变"与"3σ 上限"**共用同一个源尺寸假设** ⇒ 两条其实是一条。真正独立的往往是**内部一致性**（该物种与同族已确证物种的丰度排序是否合理）——优先检验并优先采用这一条。

**(c) 审计被质疑方的"自由参数"。** 对堆叠/匹配滤波类探测，逐个找出**由数据反演而非外部给定**的参数。最典型：**把目标分子的转动常数 B 当作自由参数**——此时"速度是否正确"这一本应独立的判据与 B 完全耦合（ΔB/B ≈ 10⁻⁵ 对应 ~10 km/s），构成 look-elsewhere 结构。这通常是全文最脆弱的点，值得写进报告。

**(d) 对"谱线混淆"指控做定量反证（本方法最有效的一步）。** 挑战方常以"该频率上有别的分子的线"为由否定。核三步：
1. **该频率是否在被挑战方的观测频段内？** 不在（如 19.19 GHz 落在 K 波段、而挑战方自己的探测文章只覆盖 Q 波段 31–50 GHz）⇒ 该混淆只是**目录预测的巧合**，是"目录层面的提醒"，不是"同谱观测证据"——**表述强度必须区别开**。
2. **混淆分子的实测线强度 vs 被挑战数据的噪声。** 取混淆分子在**同一源**的已发表线表（含 T_A* 与积分强度），与对方巡天的 rms 比较。若实测线比对方 rms 弱一个量级以上，**该混淆在量级上不可能产生被归因的特征** ⇒ 指控不成立。
3. **列表比较各自的全部分子常数。** 若能从已发表线表反推混淆分子的 A/B/C，可估算该条线的预测频率并与争议频率比对。
> ⚠️ **纪律**：第 3 步若反推所用的量子数标注存在解析歧义、或拿不到目录常数，**只能登记为"待核 N"，不得作为结论**。前两步（频段覆盖 + 量级）证据等级更高，应作为主论据。

**(e) 检查引用挂载方式（对自身稿件的真正动作）。** 找出稿件中把该观测当作**前提**的位置（而非仅作为佐证），通常表现为一句话末挂着一个引文编号。然后：
- 该前提是否**仍可由更稳健的文献支撑**？（用同族、**多条独立谱线**测定的物种作替代锚点）
- 单点引文 → 是否需要改为多引或收窄其使用范围（如从"支撑一般性失配"收窄为"长链端点的单点报告，堆叠法、未经独立确认"）。

**(f) 记录"正面收益"。** 挑战文往往也带来可用的东西：新的 μ 数据点（补进 §4 的表；注意取**区间**而非单点——同族不同来源可差 ~15%，甚至出现更极端值）、以及对自家方法的外部印证（例如对方独立写出"²Π 自由基的 Q 是闭壳层阴离子的 4 倍"⇒ 直接支持 §3 的阶梯审计）。**不要把挑战文只当威胁。**

## 关键判读规则

| 观察 | 判读 |
|---|---|
| 论文只给一个 μ，无汇总表 | μ 系统**不可审计** ⇒ 必须外部溯源 |
| μ 全部为理论值 | 该比值的系统不确定度**没有实验约束** |
| C4H 型近简并成员的 μ 被再校准 | 修正**链长依赖** ⇒ 会改变趋势形状，不只是整体平移 |
| Q(300)/Q(9.375) ≠ 32（闭壳层） | 该 Q 表被截断，**不可用于高温源** |
| μ 系统 > 自报 −1σ | 自报区间不保守，**必须加注** μ 系统项 |
| 定性结论（如"阴离子过量"） | 通常**仍成立**，只是幅度被压低——不要因幅度修正而否定定性结论 |
| 同物种在两套管线间差 **1–3×** | 这是**通用方法学偏移**的量级（实测基准：GOTHAM "4 速度分量 + 源尺寸自由" vs QUIJOTE "单分量 + 发射充满波束" = **1.3–2.7×**，6 个芳香物种）。⇒ 比这更大的偏离（如 20×）**必然含物种特有成分**，不能全归给"方法学" |
| 挑战方列举了多条论据 | 逐条查**是否共用同一假设**。典型：源尺寸—柱密度协变（(80/16)²=25）与 3σ 上限**共用 r=40″** ⇒ 实为**一条**。真正独立的通常是**同族内部一致性**（该物种与同族已确证物种的丰度排序是否合理）——优先采用这一条 |
| 挑战方的"谱线混淆"指认 | 核两步：① 该频率**是否在被挑战方自己的观测频段内**（不在 ⇒ 只是目录预测巧合，表述强度须降级）；② 混淆分子在**同一源**的实测线强度 vs 对方巡天 rms（弱一个量级以上 ⇒ 量级上不可能） |
| **要把"跨源比值差异"归因于某个 μ / Q 修订** | **先跑相消性判据**（见上文"相消性判据"）。该常数对两源都适用 ⇒ 在跨源比值之比中**恒为 0**，归因错误；只有"非对称代次"（只重算了一源）才会改变 G |
| 一个数同时被读作两种含义（如"提升 20 倍"） | **先给量下定义再算**。典型陷阱：①**跨源差距** G=R_X/R_Y；②**同源自升** R_new/R_old。**两者可巧合相等**（当"新值 ≈ 对方的旧值"时）⇒ 会被误当同一件事。先把定义写进表头，再逐项算 |
| 某条反驳（或自家论证）引文献来否定"基于新参数的推论" | **先跑循环论证判据**：该文献用的**是不是我正要替换的那套参数**？是 ⇒ 循环，作废（见案例 5A） |
| 某条观测被读作"排除某机制" | **先跑判别力判据**：若该观测**同时与假说和对立解释相容**（含未扣除的混淆因子）⇒ 记为**非诊断**，**不是反驳**（见案例 5B）。结论应写三态（证伪 / 相容但非诊断 / 支持），不写二态 |

## 已验证案例（可作模板）

**案例 1（μ/Q 溯源）**：C₂ₙH / C₂ₙH⁻ 家族 vs Remijan et al. 2023, ApJL 944, L45：
Table H2 = CDMS 逐位一致（C10H `e121501` 1336.6177；C10H⁻ `e121503` 651.7577）；Q(rad)/Q(an)@9.375 K = 3.914 / 4.387 / 4.200 / **2.051**；μ 全为理论值（C10H⁻ 已发表值张成 12.7–15.2 D）；C10H⁻/C10H = 2.0 的 **μ 系统 ≈ −37%**，大于自报 −1σ（−20%）。产出物见 `分析_观测系统性低估/03_analysis/偶极矩问题调研.md`。

**案例 2（争议探测审计）**：Cernicharo et al. 2026, A&A 713, L2 vs Remijan 2023（同一锚点被 QUIJOTE 团队质疑）。该案例示范了完整 §7 流程：
- 挑战方主张 N(C₁₀H⁻) 高估 20–30×（源尺寸协变，(80/16)²=25）与 45×（对其 3σ 上限 9×10⁹）；
- **两条论据共用源尺寸假设** ⇒ 真正独立的是 C₈H⁻ 内部一致性（8 条独立线；C₈H⁻/C₈H ≈ 1/14 vs 争议的 2.0）；
- 被质疑方的自由参数 = **B 被从堆叠反解**（11 kHz 相对变化 ≈ 11 km/s ⇒ 速度判据与 B 耦合）；
- **混淆指控被独立否证**：所指频率在 19.19 GHz（K 波段），不在挑战方自己探测文章的 Q 波段（31.0–50.3 GHz）内 ⇒ 目录预测巧合；且混淆分子 CH₂CDCN 在同源实测线 T_A* 仅 0.41–0.84 mK，而被质疑方 rms 为 2–20 mK ⇒ **弱两个量级，量级不可能**；

产出物见 `分析_观测系统性低估/03_analysis/2026_Cernicharo_C10Hminus争议_对比分析.md`。
- **后续（2026-09 系统调研，走完 §7(a2)）**：被质疑方 GOTHAM 自己的统一重分析 **Xue et al. 2025, ApJS 281, 9** 已将
  N(C₁₀H⁻) 由 4.04 × 10¹¹ 降到 **1.8 × 10¹⁰（~22×）** ⇒ 争议主体闭合，比值 C₁₀H⁻/C₁₀H ≈ 2.0 **不可再作锚点**；
  但 QUIJOTE 的 3σ 上限 9 × 10⁹ 仍**低于**该中心值 ⇒ **探测本身仍属未决**。
  家族级稳健锚点应换成 C₈H⁻/C₈H ≈ 1/14（8 条独立线）与"阴/中性比随链长单调上升"（两条独立序列，不依赖 C₁₀H⁻）。
  全流程产物见 `分析_观测系统性低估/03_analysis/CnH负离子丰度观测争议_系统调研_20260922.md`。

**案例 3（方法论级别的翻案：堆叠法 vs 逐线法）**：同一对团队（GOTHAM/GBT 堆叠+匹配滤波 vs QUIJOTE/Yebes 逐线）
在同一源（TMC-1）上的**两次**对立，示范如何把单点争议升级为**可迁移的判据**：
- 实例 1（弱信号探测）：Remijan 2023（堆叠 >9σ）→ Cernicharo 2026（未确认）+ Xue 2025（同团队下调 22×）。
- 实例 2（**非阴离子**，故更干净）：Cooke et al. 2023, ApJ 948, 133（堆叠"探测" E-1-cyano-1,3-butadiene，3.8 × 10¹⁰）
  → **Agúndez et al. 2025, A&A 697, A82**（QUIJOTE 逐线：未探测，3σ 上限 1.2 × 10¹⁰，比堆叠值低 **3.2×**；原文 "not consistent"）。
- 量化基准：**Wenzel et al. 2026, A&A**（CMZ benzonitrile）给出两团队对 6 个同物种的**通用偏移 1.3–2.7×**，
  且 GOTHAM 拟合出的源尺寸为 108″–413″（均大于 GBT 波束 22″–95″）。
- **可迁移结论**：① 遇到"堆叠 + 匹配滤波"的探测，先查同类物种在逐线搜索中的 **3σ 上限**（通常落在堆叠值的 ~1/3）；
  ② 查被质疑团队是否已在后续统一重分析中自行下调（§7(a2)）；③ 用"通用偏移 1.3–2.7×"当**分界线**——超出者必有物种特有成因。
- 附带教训：观测方自己也会写下"**两种方法都不能给出准确柱密度**"（Agúndez & Cernicharo 2026 综述），
  这是"不要把任何单一观测比值当硬锚点"的权威依据，值得直接引用。

**案例 4（相消性判据：把现象归因到 μ 之前先查它会不会约掉）**：
C₂ₙH⁻/C₂ₙH 的"冷云 vs 星周"提升被怀疑是 μ 修订的产物。**同一位数**（≈20）在两个完全不同的量上出现，
是本次的关键陷阱：

| # | 量 | 定义 | 数值 | μ 的角色 |
|---|---|---|---|---|
| ① | **跨源差距** | G = R(IRC+10216)/R(TMC-1) = 0.024%/0.0012% | **20.0×** | **严格相消（贡献 0）** |
| ② | **同源自升** | R(TMC-1, 新)/R(TMC-1, 旧) = 0.025%/0.0012% | **20.8×** | 最大单项 ×5.83（占对数增量 58%） |

- **两者为何巧合相等**：只因 Agúndez 2023 的新 TMC-1 值（0.025%）≈ 旧 IRC+10216 值（0.024%）⇒ 混合代次比 ≈ 0.96，**掩盖了真相**。
- **μ 对 IRC+10216 的实际影响**：N(C₄H) 2.96×10¹⁵ → 5.08×10¹⁴（×0.172 = ↓5.83），R 0.024% → **≈0.140%（×5.83）**；
  **阴离子端不变**（C₄H⁻ 是**闭壳 ¹Σ⁺**，无 ²Σ⁺/²Π 混合问题 ⇒ 不受该 μ 修订影响）。
- **μ 一致口径下的现代差距**：`G_modern = 20.0 × f_IRC/20.8`，且 `f_IRC ≥ 5.83` ⇒ **G_modern ≥ 5.6×**（恰 = C₈H⁻ 的 5.65×）；
  上界 ≈ 20×（若另一源也获同等重分析 ⇒ 非 μ 因子亦相消 ⇒ 差距复原）。**20 → 5.6 的下降与 μ 无关**，
  全部来自被重分析源的非 μ 部分（新谱线 ×2.63 × Q/T_ex ×1.35 = ×3.57）。
- **可迁移结论**：审计"某偏差是否为 μ 造成"时，**先判定该偏差是单源内还是跨源**。跨源 ⇒ μ 约掉，
  改去找**代次非对称**（谁被重分析了、谁没有）——**那才是最强、也最难辩驳的攻击点**（由对方论文自己的"文献值"列即可自证）。
- 产出物见 `分析_观测系统性低估/03_analysis/C4H增强20倍假说的证伪_REA温度依赖能否解释AN比_20260923.md` **§11**。

**案例 5（对"证伪报告"本身的两条卫生判据：循环论证 + 判别力）**：
同一份 C₂ₙH⁻ 证伪报告在第二轮被作者自己推翻一半。教训是：**做对抗性证伪时，先对每一条"反驳"跑下面两检**——
否则会把"用旧数据得出的结论"当成新数据的反证。

**(A) 循环论证判据（circularity test）**：若某条反驳的证据链**最终依赖你自己的工作所要替换的那套数据**，则它不能作为反驳。

- 实例：反驳条目曾引 Gianturco 2016（"C4H⁻ 需把 k_REA 压低 ~6 量级"）与 Agúndez 2023（"k_REA(C4H) too large by ~20×"）
  来否定"基于新 k_REA(T) 的推论"。但这二者的诊断都建立在 **Herbst & Osamura 2008 的旧 k_REA** 上——**正是本稿的创新点所替换的对象**。
  ⇒ **用"旧数据拟合失败后得出的机制归属"去否定"基于新数据的推论" = 循环论证**，该条撤回。
- 同类：某条反驳依赖 Gupta 2007 的"C4H 不形成偶极束缚态（DBS）"，而该前提建立在**旧 μ = 0.87 D**；
  改用 2.10 D 后 C4H 已跨过 DBS 门槛（≳2 D）⇒ **前提被抽掉，该条撤回**。
- **操作口诀**：对每条反驳问一句——"**它引的文献，用的是不是我正要推翻的那套参数？**" 是 ⇒ 标为循环，不得用。

**(B) 判别力判据（discriminating-power test）**：一条观测若**同时与假说和若干对立解释相容**，则它**既不能证伪也不能证实**假说——
应记为"**非诊断**"，而**不是**"反驳"。

- 实例：F3（"观测倍数 > 机制全温程上限"）曾被读作"机制被排除"。但**跨源比值 = REA 因子 × 环境因子**（两源密度/UV/中性来源/几何同时变），
  环境因子 ≠ 1 ⇒ 观测倍数超上限**完全在预料之中** ⇒ 只说明"**REA 不足以单独解释**"，**不等于排除**。该读法与报告自身的 F5 自相矛盾。
- 同一事实的**双刃性**：环境混淆**既阻止**别人用幅度差证伪，**也同样阻止**你把这观测写成"支持"。
- **操作口诀**：问"**这条观测落在假说自身的敏感性包络内吗？**" 是 ⇒ 非诊断（本例本稿对 C4H 速率的包络在 CSE 温度带即达 ×10–30，与效应量同量级）。

**⇒ 净结论模板**：证伪报告的结论应写成三态，而非二态——
① **被证伪**（存在有效、非循环、有判别力的反证）；
② **不能证伪但相容且非诊断**（无有效反证，但观测判别力≈0 ⇒ 相容权重≈0）；
③ **获得支持**（观测既相容又有判别力，且反证被排除）。
本例落在 **②**：可写 *"qualitatively consistent with the computed strong temperature dependence of C4H"*，
**禁** `confirms/supports/validates`、**禁**给数量级对应。

- 产出物见同一报告 **§0/§3（各条红框）/§4/§5**。
