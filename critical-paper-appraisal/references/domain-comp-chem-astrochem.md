# 专项模块：comp-chem-astrochem（计算化学 / 天体化学）

> 由 `critical-paper-appraisal/SKILL.md` 专项模块注册表引用。总体七维已覆盖的内容不在此重复——本文件只收**领域特异**检查点。每个检查点可判 pass / fail，并附建议 P 级（最终定级仍按 SKILL.md 的 finding 分级规则）。

## 命中条件（满足任一）

- 论文主体为量子化学计算：几何优化、单点能、反应路径、截面、光谱、速率常数等；
- 论文主体为分子谱线观测：柱密度、丰度（比）、探测非探测、旋转温度等；
- 理论与观测的交叉验证（"计算值与观测值符合"类声明）——此时**两份清单都要过**。

## A · 理论/计算类检查点

| # | 检查点 | 建议 P 级 |
|---|--------|-----------|
| A1 | 泛函-基组组合对该体系类是否已验证过：有 benchmark 支撑，还是仅凭惯例沿用 | P1 |
| A2 | 几何优化级别与单点能/性质计算级别是否一致；不一致时是否说明了理由 | P1 |
| A3 | 色散校正是否处理（弱相互作用体系漏加是常见系统偏差源） | P1 |
| A4 | 基组重叠误差（BSSE）是否处理或声明不适用（弱结合复合物尤其） | P2 |
| A5 | 阴离子/弥散体系：基组对额外电子是否有足够束缚能力（弥散函数、稳定性分析），否则"结合能"可能是基组伪影 | P0 |
| A6 | 声称"与实验符合"时，比较的是绝对量还是标定无关的不变量/相对量；绝对量比较是否交代了归一化约定 | P1 |
| A7 | 收敛性：活性空间、CAS/CI 外推、截断阈值、积分网格等数值参数是否做过收敛检查 | P1 |
| A8 | 非谐/热化学修正、零点能处理是否声明（与实验量直接比较时） | P2 |

## B · 观测/实验类检查点

| # | 检查点 | 建议 P 级 |
|---|--------|-----------|
| B1 | 关键物理参数（分子偶极矩 μ、配分函数 Q、T_ex）出处是否可溯； μ/Q 的系统不确定度是否传播到最终柱密度/丰度比（μ² 放大 2 倍） | P1 |
| B2 | 谱线混淆（blend）是否排查；有质疑/争议史的目标物是否讨论 | P1 |
| B3 | 波束/填充因子、光学薄假设是否成立并声明 | P1 |
| B4 | 探测显著性判据（S/N 定义、积分速度窗、stacking 方法）是否显式给出 | P1 |
| B5 | 上限的统计含义（3σ？柱密度还是丰度上限？）是否声明 | P2 |

> 需要对 B1 做定量传播审计时，转 `astro-column-density-provenance-audit` 技能执行（本模块只做"查了没有"，定量传播由专用技能完成）。

## C · 交叉验证类附加检查（A∩B 命中时）

| # | 检查点 | 建议 P 级 |
|---|--------|-----------|
| C1 | 理论值与观测值比较时，双方物理约定（平衡结构 vs 振动平均、0 K vs T_ex）是否对齐 | P1 |
| C2 | "符合"是否给出定量判据（区间重叠、χ²、比值一致），还是目测重叠 | P1 |
| C3 | 标定无关性：比较是否依赖某一方的绝对归一常数（对接 `cross-paper-curve-comparison` 的不变量方法） | P1 |
