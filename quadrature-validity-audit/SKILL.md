# 数值求积合法性审计（Quadrature Validity Audit）

## 何时用

- 有人（或你自己）以"**加密网格 / 提高阶数后收敛**"为依据下结论 —— 先审计求积是否**合法**，再谈收敛。
- 同一标量在不同网格下**量级突变或变号**（最廉价的缺陷探针）。
- 高阶求积（Lebedev / Gauss / 稀疏网格）被认为"点数最多所以最好"。
- 结果依赖"角度平均""球平均""投影到某基"等**积分型中间量**。

## 核心洞见

> **"点数够 ≠ 求积合法"。** 求积规则的**节点数**与它能否正确积分**非多项式被积函数**是两件独立的事。
> **谐波/单项式精确度**只保证对**低阶多项式**精确；对 GTO 角向密度、库仑型势这类非多项式被积函数，**权重非正**的规则会失去"加权平均"语义，导致符号不定与不收敛，而**度数判据对此完全盲**。

## 三检（必做，全部廉价）

### 检 1 —— 权重正性与归一化
```
w = rule.weights
assert w.min() >= 0                     # 非正权重 ⇒ 立即标红（规则非法/特殊）
assert abs(w.sum() - 4*pi)/4/pi < 1e-12 # 球面积分归一化（依约定）
```
- **负权重不是四舍五入噪声**：若出现（如 wmin ≈ −0.7，量级远超典型权重），即为**结构性**问题。
- 注意：某些已发表规则表（如经典 Lebedev 表的若干序）**确实带负权重**；它们仍可能谐波精确，但**不可用于非多项式被积函数**。

### 检 2 —— 在解析基上的精确度
对球谐 `Y_lm`（或 1D 单项式 `x^n`）做逐项积分：
```
sum_j w_j * Y_lm(Omega_j)  ==  sqrt(4*pi) * delta_{l0} delta_{m0}   # 对 l <= L_deg
```
- 全线 ~1e-15 ⇒ 该规则对**低阶**精确（**但不证明**对非多项式被积函数可靠）。
- 某阶大面积失败 ⇒ 规则的**设计阶数**低于你所要求的 l（预期，不是 bug）——须区分"阶数不足"与"权重非法"。

### 检 3 —— 守恒量残差（最关键，且不依赖"相邻档收敛"）
把**积分型中间量**与**解析不变量**对比：
```
4*pi * int  rho_bar(r) r^2 dr   ==  Tr(P . S)      # 电子数守恒
```
- **相对判据（"相邻档差 <5%"）会被系统性偏置掩盖**：两条都错到同一个方向时，相邻差可能很小。
- **绝对判据（守恒量残差）是独立证据**：它不依赖"另一个网格"，因此不会与坏网格共谋。
- 实测反例（本项目）：`∫4πr²ρ̄dr` 在 n_ang = 26/86/230 下 = **62.5 / 23.9 / −3.5**（应 ≈ Tr(P·S)）⇒ **完全不收敛**，而相邻档"看起来在收敛"。

## 判定与处置

| 症状 | 判定 | 处置 |
|---|---|---|
| 权重含显著负值 | **规则非法**（用于非多项式被积函数） | 换**全正权重**的相邻序（如 170/194/350 替代 230） |
| 谐波仅对 l>L_deg 失败 | 阶数不足（预期） | 提高阶数 |
| 守恒量残差 ≫ 1e-6·参考量 | **归一化/求积不守恒** | 不得采信该网格的任何"收敛"结论 |
| 跨网格标量范围量级突变/变号 | **优先怀疑求积**（而非物理） | 走本审计三检 |

## 汇报纪律（关键）

1. **区分"确定性部分"与"未测量部分"**：
   - 确定：求积非法 + 守恒量不守恒 + **审计依据失效**。
   - 未测量：缺陷对**最终可观测量的定量影响**（须在合法网格上复跑后才能说）。
   - **不要**把"审计依据失效"写成"结论已被证伪"。
2. **给结论打 🔻"待合法网格复核"**，不删原行（留痕）。
3. **同时给出守卫（轻）与结构性修正（重）**：
   - 轻 = 在求积入口对负权重序发 `UserWarning`；把"权重全正 + 守恒量残差"增补进验收判据。
   - 重 = 更换目标网格/阶数（通常需授权）。
4. **升级既有方法论条目**：把"度数判据不足"（点数够 ≠ 投影够）与"求积不合法"（点数够 ≠ 合法求积）作为**同一缺口的两个实例**并列记录。

## 反模式（别做）

- ❌ 只看 `Σw = 4π` 就判定规则可用（归一化正确 ≠ 权重非负）。
- ❌ 只用"相邻档 <5% 收敛"作为唯一判据（相对判据会与坏网格共谋）。
- ❌ 用"点数最多"作为选网格的理由。
- ❌ 发现负权重后直接断言"最终结果已被证伪"（先量化影响再定性）。
- ❌ 在慢的生产路径上做多网格扫描（先用快 1–2 个数量级的诊断路径钉死结论）。
