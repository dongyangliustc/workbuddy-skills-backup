# 专利代理机构接洽流程（科研单位场景）

## 何时用

科研人员/国家实验室研究人员要为一项发明申请专利，需要联系代理机构，且**申请人主体是单位而非个人**。
典型提问："如何联系某代理所""专利申请委托的流程""单位要求我们自己先联系代理，确认后再报备"。

## 核心事实：流程通常是两段式

多数科研单位（高校、国家实验室）的实际规则是：

```
个人先期接洽 → 与代理所确认合作意向 → 报备至单位 → 单位出面签署正式委托并提交申请
```

**这个事实决定了一切措辞**：首轮联系时个人**不是委托方**，只是技术对接人。邮件中必须写明这一点，并在署名处声明"本邮件为先期技术接洽，正式委托以单位签署的委托合同为准"，否则对方可能认为委托关系已成立。

## 四段式执行方案

| 阶段 | 动作 | 硬约束 |
|---|---|---|
| 一 · 先期接洽 | 发出询价函，取得流程说明、报价、代理师安排 | 不披露任何技术内容；不作有约束力承诺 |
| 二 · 材料收集 | 索取报备材料包，核对完整性与有效期 | 缺项会被单位退回补充 |
| 三 · 单位报备 | 按单位要求提交报备，取得审批意见 | **此阶段结束前不向代理所提供技术内容** |
| 四 · 正式委托 | 单位签署委托合同 → 签保密协议 → 提交技术交底 → 撰写申请 | 保密协议必须先于交底 |

## 首轮询价邮件的七问结构

1. **委托流程与材料**：从接洽到提交的完整流程、各环节时间、需单位配合的节点；交底书格式要求；主体资格证明要求。
2. **保密安排**：能否先签 NDA 再交底；能否提前提供 NDA 模板审阅。
3. **费用与周期**：代理费、官费、超项费、审查意见答复费、优先审查请求费分别如何计算；交底到受理的周期；能否走优先审查或地方知识产权保护中心预审通道（需先确认单位是否已完成预审主体备案）。
4. **报备材料**（关键，见下）。
5. **合同与结算主体**：能否与单位直签；单位需比价/招标时可否提供支撑文件；发票类型与开票主体；能否"先 NDA、待内部审批完成后再签正式合同"。
6. **代理师安排**：能否指定在对应 IPC 分类有撰写经验的代理师；能否提供 2–3 件同类授权案例。
7. **我方基本情况**：申请人主体、共同申请人、发明人、申请类型（仅中国 / PCT / 海外）、**对外公开情况**、期望时间节点。

## 报备材料清单（必须主动索取）

单位内部审批的刚需，缺一项通常退回补充：

- 机构资质证明（营业执照、专利代理机构注册证复印件）
- 拟承办代理师的**执业证号**与简要履历
- **盖章的正式报价函**（费用分项列示）
- 同类领域已授权案例清单
- 保密协议（NDA）模板、专利代理委托合同模板
- 服务方案与时间计划

## 六条合规红线

1. **首轮不得作有约束力承诺**：用"拟委托""如贵所有初步意向""待单位审批"，不写"我方确定委托贵所"。
2. **不越权**：不代单位作价格、排他、付款承诺；签约与付款主体一律指向单位。
3. **报备在确认合作之后**，须主动向对方说明，避免其误判已进入正式委托。
4. **不留技术痕迹**：首封邮件不附图纸、代码、算法描述、基金/项目编号。
5. **涉密审查**：涉及国家秘密须先经单位保密部门批准，未解密状态不得对外披露，甚至不得申请普通专利。
6. **职务发明归属**：权属归单位，主体、经费来源、内部审批须先行厘清。

## 需向用户/单位确认的清单（缺则无法定稿）

- 申请人单位全称（须与公章一致）、个人姓名、手机、单位邮箱
- 部门与身份职称（影响报价档位与代理师分派）
- **邮件中可披露的技术方向粒度**（由用户划定保密边界）
- **是否已对外公开**（论文投稿/接收、学位答辩、开源、会议）及时间 —— 时效风险最高项，中国专利宽限期极有限且通常不覆盖普通论文公开
- 是否需 PCT / 海外布局
- 共同申请人（决定联系哪家代理所）
- **单位是否要求比价（≥2 家报价）** —— 若要求，须同时独立发出询价且正文不提及竞洽
- 单位是否已有入围名单（有则本流程仅用于确认对接人，不得超出名单接洽）
- 报备受理部门、所需材料、审批时长（决定"期望时间节点"能否写实）
- 合同签署与付款主体、是否需走政府采购/招投标、发票类型
- 项目密级、是否属职务发明
