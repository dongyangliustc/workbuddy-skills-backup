# 跨文献曲线比对（归一化无关不变量法）

## 这个技能解决什么

你有一条自己算的曲线 σ(E)，对方论文只给了图。常见的三个陷阱：

1. **绝对量不可比** —— 对方的纵轴含未知归一常数（Dyson 归一、单位换算、模型依赖因子），硬比绝对值必然被审稿人打回。
2. **横轴基准不同** —— 双方阈值/零点差几十到几百 meV，按同一横轴比会给假结论。
3. **比值被误当成证据** —— 拿到一个"差 20 倍"就写结论，但没排除锚定、稀释、命名三类平凡解释。

本技能给出一个**只依赖不变量的判定流程**，让结论在上述三类反驳下都站得住。

---

## 第 0 步：先定"可判定的问题"

把模糊需求改写成一句**可证伪的命题**。坏例："和那篇比一下对不对"。好例：

> "我们的 σ_Σ/σ_Π 随链长上升，对方的是否也上升？"

可判定性检查：这个命题能否只用**双方共有的、标定无关的量**回答？不能就先改问题。

---

## 第 1 步：取数 —— 优先 PDF 矢量层，不要扒位图

**判据**：`page.get_drawings()` 能返回路径 ⇒ 用矢量层；否则退化为位图（改走 `chart-digitizer`）。

矢量层的优势是数量级的：位图在**对数轴**上标定误差可达几个数量级，且曲线交叠处不可分。

```python
import pymupdf                       # 不用 fitz（已弃用）
doc = pymupdf.open(pdf)
page = doc[pno]
# 定位图所在页：用图注文本反查，不要靠"第几页"猜
hits = doc[n].search_for("FIG. 5.")
draws = page.get_drawings()          # 每条: color / fill / dashes / width / items / rect
```

要点：

- **坐标轴框** = 图元里面积最大的矩形路径；**主/次刻度**按图元长度分级（如 `len >= 3.0` 为主刻度）。
  先用 `drawings` 里的 `re` 图元找出候选框，再按 `150 < width < 215 and 40 < height < 200` 之类的窗口过滤。
- **标定** = 主刻度坐标 ↔ 轴标签值，做最小二乘；**次刻度做闭合校验**（应落在整数格点上）。
  验收线：横轴残差 ≲ 0.2 meV、纵轴 ≲ 3e-4 dex。达不到就回查刻度分级。
- **曲线身份靠颜色 + 线型**：`(color, dashes)` 组合。同色两条不同线型的曲线极易被算法混为一条。
- **同一条曲线常被切成多段**（虚线间隙、被坐标轴裁掉、被标签打断）。求该通道的**有效跨度**时必须取
  **各段并集的 `[min(first), max(last)]`**，并在段落之外记 **0**（真正的零）而**不是**记 floor（贴轴值）。
  否则 `min(E[-1])` 会取到某个内段末尾，跨度为空，后续全崩。

> 反面教材：某次 `C6H-_Sigma` 面板里品红曲线被切成 `[4.104,4.307]` 与 `[4.319,6.5]` 两段，
> `min(E[-1])` 取到 4.307 < `max(E[0])` = 4.319 ⇒ 网格长度为 0 ⇒ `IndexError: index 0 is out of bounds for axis 0 with size 0`。

## 第 2 步：**三重锁定**图注归属（不可跳）

跨文献比对最常见的翻车不是算法，是**看错图**。至少做三层独立校验：

| 层 | 做法 | 通过判据 |
|---|---|---|
| ① 图注原文 | 从 PDF 正文抽图注，逐字读 | 明确写出每条线/每个面板对应哪个物理量 |
| ② 物理自洽 | 用原文对**分波/分项主导项**的叙述去核对图面 | 例如原文说"p 波主导 A 态"，则 A 态那组里 l=1 应最大 |
| ③ **反演闭合** | 用对方的已知因子把分项加和回它自己的总量，与总量图比 | 近阈应吻合到 ~10% 内 |

**第 ③ 层是硬证据**：如果归属错，反演不可能在阈值附近闭合。它同时验证了对方的求和口径（例如"图里只画了 l ≤ 2，总量却含 l ≤ 9"—— 这个差异应表现为**高能端系统性偏低**，而不是近阈偏离）。

⚠️ 必查两件事：
- **图注可能有印刷笔误**（我们遇到过把 C2H⁻ 写成 C6H⁻ 的图注）。用 ② + ③ 交叉锁定。
- **相邻两张图的上下栏可能相反**（Fig.5 上Σ下Π，Fig.9 上Π下Σ）。这是最易致错处，逐栏核对主导项。

## 第 3 步：挑**归一化无关**的不变量

只比能消掉未知常数的量：

| 可用（推荐） | 不可用 |
|---|---|
| 同物种同能量的**通道比** σ_A/σ_B | 绝对截面 |
| 同通道不同能量的**比值/斜率** | 绝对 \|I\|² |
| **log-log 斜率**、形状指数 | 单位不同的量直比 |
| 同一量的**跨物种趋势方向** | — |

选好后写清它**为什么**与归一化无关（一句话），这句话就是结论的免疫证明。

---

## 第 3.5 步：**口径独立性检验**（★ 最易漏，代价最大）

"归一化无关"**不等于**"口径无关"。同一个物理量常有多种产出方式（规范 / 版本 / 分支 / 近似 /
单位制），其中**可能有一列根本不是独立量，而是其他列的算术平均或线性组合**。

**必做两问**：
1. **它来自哪一列？** 该列是原始量，还是下游派生量？（去查产出方的源码 / 文档，不要猜）
2. **换一列会怎样？** 若同一量有多列，全部算一遍；若只给了一列，**先怀疑它不独立**。

**独立性验证**：用逐点恒等式反查（例如 `colC ?= (colA+colB)/2`），报最大相对偏差。
**敏感性量化**：只换列、其余全不变，看结论漂移几倍，给出**包络区间**（各列的 min–max）。

> 实例（C₂H⁻ 光脱附，2026-09）：判据列 `cross_mix` 经逐点反查恒等于 `(length+velocity)/2`
> ——**72 个网格点全部 = 1.000000**。后果：分通道比值随读哪列漂移 **6–56 倍**；
> 带积分比值随读哪列漂移 **3.5–23.8 倍**。一度准备写进稿件的"两理论一致到 1.5–2.2 倍"，
> 实际是**规范未定**：换列后为 3.5–4.4（length）或 0.2–1.0（velocity）。
> **一个通过了"归一化无关"却没过"口径独立"的判据，其倍数陈述不可引用。**

**判据**：若换列造成的跨度 ≳ 1.5×，结论**只能写成包络**（附各列区间），不得写成单点倍数。
若跨度 ≳ 5×，说明判据本身尚未定义清楚 —— 此时应停下，先去产出方确认哪一列是该物理量的正确口径。

**顺带检查数据可得性**：若最关键的区间（如阈值附近）恰好**只有一列**，这本身就是缺陷，
要明确写进交付物（"该区间无法做口径审计"），并建议重跑时补齐列。

---

## 第 4 步：**锚定不变性**（抗反驳 A）

双方阈值不同时，按谁的阈对齐会改变结果。**必须两套都算**：

- 口径 1：按各自 **A 阈** 对齐（E_A + ΔE）
- 口径 2：按各自 **B 阈** 对齐（E_B + ΔE）

结论只在**两套都给出同号同量级**时成立。若只在一种锚定下成立，那结论就是锚定假象。

---

## 第 5 步：**稀释核算**（抗反驳 B）

对方如果引用了自己的已知因子（如 \|S₀₀\|²、分支比、缩放常数），把它们乘进比值算一遍。

> 判据：**若该因子只能给出 ≤1.2 倍的改动，它就不可能解释 10 倍以上的分歧。**
> 一句话写进结论："X 只承担 ≤1.2 倍，不足以解释 N 倍。"

---

## 第 6 步：**标签互换排除**（抗反驳 C）

如果两侧都在用 A/B 两个同名通道，必须排除"其实两边 A、B 叫反了"：

**看序**：两个独立方法对"哪个通道的阈值更低"应给出一致排序。
**三物种全部一致 ⇒ 标签未互换**。若出现不一致，先查这个，再谈物理。

> 这一步极关键：曾出现"若把 Σ/Π 对调，两个物种的分歧从 ×13 变成 ×1.3"的情形 ——
> 表面看像是命名错位。是阈值排序把它定死：三物种排序双方完全一致 ⇒ 分歧是真的。

---

## 第 7 步：结论语言纪律

| 情形 | 可写 | 禁写 |
|---|---|---|
| 形状同构但常数不为 1 | "R_ours(E) 与 R_ref(E) 成比例（log-log 斜率 ≈ 0），比例常数按物种为 X–Y" | "两者一致" / "差异只是归一化" |
| 形状不同 | 给出斜率/残差数字 | "趋势相同" |
| 分项差异但不能定谁对 | "两方在 X 上相差 N 倍；本比对无法判定谁更准" | "本方法更准确" |
| 只做了总量 | 只谈总量 | 谈任何分项归属 |

**永远不要**把"某机制不能解释该差异"写成"该机制被否定"。正确写法：
"该机制的贡献量级被圈定为 ≤K 倍，不足以覆盖实测的 N 倍。"

---

## 第 8 步：**定量判据的统计纪律**（★ 第三类陷阱"比值被误当证据"的真正补丁）

第 7 步管住"怎么说"，这一步管住"用什么数字说"。比值是**乘性量** ⇒ 一切统计在 **ln 尺度**上做。

### 8.1 中心与离散度：ME → GM，RMS → GSD

| 旧 | 新 | 定义 |
|---|---|---|
| ME（比值算术均值） | **GM**（几何均值） | `exp(mean ln r)` |
| RMS（比值均方根） | **GSD**（几何标准差） | `exp(sd ln r)` |

**先核对旧数字是不是本来就在几何尺度上**（`exp(mean ln r)` 是否已等于所报 ME）。本例中恰好相等 ⇒
旧数字的量级族没错，缺的只是 CI 与自相关校正。**不要为了"规范"去改一个本来就对的数。**

### 8.2 n 不是独立样本数（**最常被误用**）

密集网格相对物理曲线严重过采样。必须算 **积分自相关时间 τ**（Sokal 窗法，初始正序列截断）与
**有效样本数 `neff = n/τ`**。

实测：n = 1911 的网格 Σneff 仅 **19.7**（压缩 97:1），单体 τ 可达 208 ⇒ 按 n 算 CI 会窄一个数量级以上。
**推论（对作者极重要）**：**加密网格不改善任何 CI** —— 宽度由曲线光滑度决定。要提精度只能加**独立**维度
（更多物种 / 更宽能量域 / 独立方法），不是加网格密度。

### 8.3 区间：两个估计器互为对照，且各有一个必踩的坑

- **批均值法**（batch means，t 区间）—— **主口径**，无分辨率地板。
- **块自助法**（moving-block bootstrap）—— 主对照。

1. 块长若取 `ceil(3τ)` 而 τ 很大 ⇒ 块数只剩 3–4 ⇒ **CI 下界 > 中心**（退化）。**块长必须封顶 `n/8`**，保证 ≥8 块。
2. **bootstrap 的 p 会撞地板 `1/B`** ⇒ 所有格都报同一个 `2.5e-4`，无法区分 `3e-4` 与 `1e-30`。
   **p 值主口径改用批均值 t 检验**，bootstrap p 仅作对照并注明地板。

### 8.4 等价性门控：**"无显著差异" ≠ "等价"**

必须三分，不能二分：

- `CI ⊂ [1/1.25, 1.25]` ⇒ **EQUIVALENT**
- CI 排除 1 ⇒ **SIGNIFICANT DIFFERENCE**
- 否则 ⇒ **INSUFFICIENT EVIDENCE**（宽 CI 既可能"差异真小"也可能"样本不够"，必须报告而非隐藏）

### 8.5 趋势用 HAC，不用朴素 SE

拟合 `ln r = a + b·ln(ΔE)` 时残差自相关 ⇒ 朴素 SE 假性变小。用 **Newey-West HAC**，滞后阶取 `⌈τ⌉`。

**非零斜率是有力证据**：任何**常数**因子（FC 近似、归一化、比例常数）都只能移动截距 `a`，
**无法制造斜率 `b`** ⇒ `b` 显著非零即意味着**形状层面的真实分歧**，须与倍率差异分开记账。

### 8.6 原点敏感性：阈值位置是独立量

双方阈值各自独立测定，相差几十 meV。把 ΔE 整体平移 δ ∈ {−50, 0, +50} meV 重算分层：

- 全能量域的中心统计量**构造上平移不变** ⇒ 最稳健，优先对外；
- **窄带（带宽 ~ 2·δ_max）会摆 20%+** ⇒ 该带的任何具体数字**不得对外**；
- 宽带若稳定（≤5%）方可引用。

### 8.7 小样本 vs 大样本的权重

实验对标点常只有个位数（本例 n = 6，且 2 能量 × 3 物种 ⇒ 既不独立又极少）。

- **配对比较**（逐点相除）能抵消共同噪声，但 n 小时其 bootstrap CI 与**符号检验会冲突**
  （本例 CI 排除 1 而符号检验 p = 0.22）⇒ **必须两个都报**。
- **权重交给大样本**：若同一倍率已在密集网格上确证（本例 GM ≈ 2.0、CI 下界 1.15、neff ≈ 20 ≫ 6），
  就以它为准，把小样本比较写成"**提示**"而非"**判定**"。

### 8.8 ★★ 两套数字对不上时：**先排查三件事，再决定要不要问用户**

同一项目里常有两份文档给出同一"不确定度"的不同值。**不要把它当成"口径随便选一个"抛回给用户**——
九成情况下它不是选择题。按顺序查：

| # | 问 | 怎么查 | 本例实测 |
|---|---|---|---|
| 1 | **是同一批数据吗？** | 追到源文件/源表，不要停在转述文档 | `比值曲线.csv` 其实是**本文/Douguet**，不是本文/Best；Best 数字在另一个 `_threeway_tables.npy['best']` 键里 |
| 2 | **是同一个量吗？** | 看定义式：**相对 1** 还是 **绕均值** | `RMS 3.21`（相对 1 = 偏倚 ⊕ 散布 = **单点预测不确定度**）与 `GSD 3.13`（绕均值 = **只在散布**）是**两个不同的量**。当前网格上二者几乎重合（3.129 vs 3.128，偏倚仅 0.20 dex）⇒ 该选择数值上无关紧要。恒等式 `RMS² = ME² + SD²` 是判据 |
| 3 | **是同一个估计方法吗？** | 小样本的百分位自助**天然过窄**（n = 6 时无法刻画 t 尾） | 同批数字：自助 `[0.62, 3.33]` vs **Student t `[0.48, 5.28]`** ⇒ **取 t**，且注明 6 点不独立故仍偏乐观 |

**另一条更常见的过期源：网格代次。** 项目里的网格会被加密，而旧文档的数字不会被回溯更新。
验证法：用**当前**细网格做最近点取值，与文档值比较——吻合到 4–5 位说明该文档就是当前口径；
系统性偏离说明它出自旧网格（本例 C₂H⁻@3.04：新 **0.1512** vs 旧 **0.134**，差 11%）。

**顺带一条稳健性技巧**：把"判据线"当成一个**区间**而不是一个数（本例同时跑 2.83 / 3.13 / 3.21），
若结论在所有候选下不变，就在文中写出来 —— 这能一次性消灭"你凭什么取这个阈值"的质疑，
也免去请用户裁定口径。

### 8.9 ★ 多个对照物时：并列表 + **分带**（单个全局数字会掩盖结构）

当同时存在 ≥2 个对照物（实验点 / 前人理论 / 经验外推），正确交付物是**一张并列表**：每个对照物各给
偏倚（GM）、散布（GSD）、RMS（相对 1）、CI、判定。但**并列表本身不够** —— 必须再加一层**分带**。

**为什么分带是必需的（本例实测）**：分带（ΔE = 0–0.3 / 0.3–1.5 / 1.5–3.0 / >3.0 eV）暴露出两个对照物的
偏差形状**正好相反**：

| ΔE 带 | vs 经验外推 | vs 前人理论 |
|---|---|---|
| L1 近阈 | 0.70 / 1.46 / 2.23（≈1，**准**） | 0.38 / 2.24 / 4.27（**跨度 11×，最乱**） |
| L2 | 3.90 / 3.75 / 6.88（**跳升**） | 2.90 / 2.78 / 2.38（收敛中） |
| L3 | 4.88 / 5.87 / 14.05 | 2.28 / 1.70 / 1.55 |
| L4 高能 | 4.00 / 6.68 / **18.63**（**发散**） | 1.71 / 1.32 / — |

⇒ 一句话：**与外推的分歧在近阈最小、随能量发散；与前人理论的分歧在近阈最大、随能量收敛。**
**这句话决定了两个对照物各自能被引用的能量范围**，而任何单一的全局倍数都看不到它。

**三条硬纪律**：

1. **分带必须带"独立点计数"列**（native / neff）。本例外推列 L1 的 native 只有 1/1/0 ⇒ 那一行
   **不得出具体数字**。把既有禁项（"近阈带不可引"）从"口头纪律"变成**表里可核查的一列**，
   图里则用**空心标记**编码同一约束。这是最省事的防误引手段。
2. **不同对照物的 CI 不可横比**：n = 6 的非独立实测点 vs ~2000 个网格点（neff ≈ 20）——
   样本结构不同，区间宽度不在同一尺度上。**只有中心（偏倚）可比。**
3. **有的对照物可以池化，有的不可以**：若偏倚跨子群高度一致（本例 2.09/2.00/2.06，散布 <5%）⇒ 可给
   单一数字"约 2 倍"；若偏倚本身随子群单调变化（本例 3.94→14.95）⇒ **那个变化就是结论，池化即误导。**

### 8.10 同一组数字在两份文档里对不上（见 §8.8）之外，还要查 **τ 的实现**

自相关时间 τ 的估计值随具体实现（窗函数、截断判据、作用在 ln r 还是 r 上）可差 10–15%
（本例 61–331 vs 59–208），因而 CI 宽度带有同量级的实现不确定度。**引用 τ 或它的 CI 时要随带这句**，
并确认它不影响 SIGNIFICANT / INSUFFICIENT 的**判定**（本例不影响）。

### 8.11 ★★ 「能否声称平均系统性大 N 倍」——四条件（★ 用户若问"我能不能说系统性差几倍"，答这个）

**问题形态**：用户看到偏倚中心（GM）是 2.0，想写 *"ours is systematically a factor of 2 larger"*。
**默认回答：不能只看 GM 的数值。** 该措辞需**四个条件同时成立**，缺一即降级。

| # | 条件 | 校验方法 | 降级后果 |
|---|---|---|---|
| (i) | **CI 排除 1** | 看 CI 是否含 1（含 ⇒ 偏倚可归零） | 出局，只能写"证据不足" |
| (ii) | **幅度连区间一起给** | 报 `GM [lo, hi]`，不报裸点估计 | 不可核，等于没报 |
| (iii) | **逐点 >1 比例** | `mean(r > 1)`，并看 p10 是否 >1 | 若有反向子群 ⇒ **只给方向** |
| (iv) | **聚合层级正确** | 逐子群 GM 的**跨度** | 跨度大 ⇒ **禁池化**，跨度即结论 |

**三条可复用细则**

1. **逐点比例是区分"系统性"与"平均偏大"的唯一杠杆**。中心偏大完全可能伴随反向子群：
   本例 C₂H⁻ 在**两个**对照物下分别有 **9.1% / 2.4%** 的点方向相反 ⇒ 该物种只能写方向。
   **经验线**：≥99% 用"with CI"；90–99% 用"direction only"；有 CI 但逐点 <90% ⇒ 连方向都要加限定。
2. **可池化性由跨度决定，不由 CI 是否排除 1 决定**。本例 ② 跨度 **1.05×**（可给"约 2×"）、
   ③ 跨度 **3.80×**（禁池化）。判据：跨度 <1.25× 视为单一数字，>1.25× 必须逐子群列。
3. **大样本的 p 有地板，且 p 不衡量效应**。批均值的 `df = 批数 − 1`（本例 7）⇒ p 有 ~1e-3 分辨率地板；
   `p < 1e-3` 与 `p = 1e-8` 在该口径下**不可区分**，写 "<1e-3" 而非具体值。

**输出模板**（依次给这四项，措辞自然可分档）

```
✅ YES, with CI      : "ours exceeds <X> by a factor of <GM> (95% CI <lo>–<hi>)"
⚠️ direction only    : "ours tends to exceed <X>, with <p%> of points in the opposite direction"
⛔ NOT supportable   : "the evidence is insufficient to establish a systematic offset"
```

**同源纪律**：四条件判据应写成脚本的一个自动节（本例 `bias_structure_tables.py` §4b），
verdict 由代码算出而非人工判读 ⇒ 报告、表格、图永远同源，且可逐位复现。

## 第 9 步：**比较对象可能是解析式，而不是数据点**（★ 当对方产物由闭式律生成时）

**触发判据**：对方的曲线/表格/数据库条目不是"测量点"，而是**用少数标定点去定参的闭式经验律**。
此时**不要去比那几个标定点** —— 去比**那条律本身**。

**为什么更强**（三条，缺一不可）：

1. **能量域不受限**：闭式律在任意自变量处可求值 ⇒ 比较域可推到物理上限（Lyman limit、阈、溶解限……），
   与自家数据的覆盖范围对齐；而比数据点只能比那几个点。
2. **它就是实际输入**：模型/数据库消费的是这条律，不是被它拟合的测量点。批判对象与致害对象在此重合。
3. **可剥夺借口**：可以构造"最有利"变体，逼对方承认是**函数形式**的失败，而不是**参数拟合**的失败。

**执行顺序**：

0. **★ 先验证函数形式本身——尤其是指数。不要相信 PDF 文本抽取出来的式子。**
   - PDF 转文本会**吞掉上标/根号**。实战中一个 `(1 − EA/ε)^{1/2}` 被抽成线性式，
     位置处只剩一个控制字节（`\x02`）；照抄就会把对方的**正常拟合**误判成**系统性偏差**。
   - **两条独立校验，必须都做**：
     ① **对方自己的自洽性主张**：作者通常会在正文里说"该式在某极限下收敛到某已知律"——
        拿它反推指数。实战：原文称"ε→EA 时收敛到 Wigner s 波律 σ ∝ √(ε−EA)"，
        而 √ 阈行为**只有指数 1/2 才能给出**。
     ② **单参数反演**：用对方公布的参数值，反解"什么指数能让它等于由其**自身标定点**
        做单参数最小二乘所得的参数"。哪个指数把公布值还原出来，哪个就是真形式
        （实战：指数 1/2 给 4.84 vs 公布 4.80；指数 1 给 20.5）。
   - 还可以**求外部复用**：同一式常被后续文献逐字重写，其 LaTeX 源里根号是显式的。
   - **反例自查**：若某式推出"对方连它自己的标定点都重现不了、且残差**同号**"，
     按统计学直觉这就该先怀疑**自己的式子**（正常拟合的残差必须**符号混合**）。
1. **定位出处链**（至少三环）：引入该式的原始文献 → 定参文献 → 下游采用者。
   下游采用者的措辞（"adopting/constructing … based on …"）决定它到底是"原样搬参数"还是"自行重拟合"。
2. **★ 读 TABLE CAPTION，不只读表**：阈值/基准/被固定的量常常只写在表注里。
   只读表体会用错参数（本方法实战中差一点用错整组阈值）。同时记下**拟合层级**：
   哪些子集用的是单参数、哪些是双参数（作者常因数据不合而临时多放一个自由参数）。
3. **构造变体族**（至少三个）——**但先问"下游到底用哪一套"**：
   若已能证明下游用的是**已发表定参那一套**（见第 4 条末段的独立可观测量判据），
   就**只比那一套**，不要为"显得稳健"而引申变体：变体越多，越容易把作者自己承认的
   "该式对本物种拟合不好"误当成"对方数据有错"，反而给审稿人送把柄。
   确需变体时（下游口径不明）：
   - **V1 原样默认**（该式早期的假定值，即"批判对象之前"的版本）；
   - **V2 已发表定参**（主口径）；
   - **V3 最有利 / 精确穿过标定点**（"best possible"：解出参数使曲线**逐一穿过**对方的标定点）。
     ⚠ 两点精确解往往是**病态的**（两点能量相近 ⇒ 参数摆动数倍、解出非物理值）——
     这本身就是"该式不可外推"的量化证据，要保留而不是丢弃；
   - **V4 把参数重拟合到标定点**（最朴素、也最可能是下游实际用的版本）。
   **每个变体单独出结论**，先看结论是否对变体不变。
4. **若头号数字随变体翻转**（实战：已发表定参给"约一个数量级"，而重拟合变体只给 1.1–3.5 倍）⇒ **必须判别**，
   不能挑一个顺手的变体写进论文。判据是**另一个由同一对方产物派生的独立可观测量**
   （实战：对方数据库里**同时列出的速率**，而不是被比较的那个量本身）。
5. **判别手法（可复用）**：对方与自家的该可观测量都是同一泛函 `O = ∫ f(x) W(x) dx`（W 未知）。
   用**自家的**若干条 `O` **反解** W（少量 bin + NNLS），**先自校验**（能否重现自家 `O`；实战中做到 1.7%），
   再回代各变体预测对方的 `O` 并比对。判别力来自"变体间预测差几倍"，不来自 W 的物理意义——
   **报告时务必声明 W 只是拟合仪器**。
6. **顺手做对方的自洽性检查**：用**对方自己的**参数代入**对方自己的**标定点。
   若有偏离，先查清是否**拟合目标不同**（例如拟合的是整段扫描谱的形状，而非那几个绝对点），
   再决定能不能称之为错误。**拟合目标不同 ≠ 对方错误**，措辞纪律见第 7 步。
7. **区间只报在原生采样上**：把插值网格上的点数当 n 会虚高一个数量级以上（见 8.2）。

**与第 3.5 步的分工**：第 3.5 步查"同一量在对方文中的两种口径"；本步查"对方产物由哪个式子生成、参数是哪一组"。

## 高频踩坑速查

- **键名拼接产生双横线**：`sp + "-Sigma"` 在 `sp="C2H-"` 时得到 `C2H--Sigma`。一律 `sp.rstrip("-")`。
- **★ 判据列其实是派生列**：工具输出 `colA/colB/colC` 三列，`colC` 恒等于 `(colA+colB)/2` —— **不是第三种口径**。用它算出的比值 = "只读了一列"的产物。**必查逐点恒等式**（见第 3.5 步）。最坏情形：该列把某个通道砍半、总量被压低 36–48%，而这一点从数字表面完全看不出。
- **★ 同一表内并排两套网格**：粗块与细块只差一个列偏移，粗块与细块**起点可能差一行**（不同物种不一致）⇒ 读块须"跳过前导空行、遇到首个空行才终止"，别用固定行号。
- **★ 细分网格锚在不同物理量上**：一套锚 VIE、一套锚 AIE，两者相差数百 meV。用错锚的网格去覆盖近阈带 ⇒ 该带"没有数据"而看不出原因。先列**每个块的原点**再动手。
- **`np.trapz` 已改名**：numpy ≥2.0 用 `np.trapezoid`（`np.trapz` 直接 AttributeError）。
- **两个通道网格不同**：带积分**各自积分后相加**即可（积分可加），不必先插到共同网格。
- **网格空隙**：自己的近阈网格止于 4.19 eV，对方的某通道 4.21 eV 才起始 ⇒ 交集为空。必须准备第二套（宽网格）并说明为何切换。
- **自家两套网格互相打架**：结论要给**区间**而非单值，并说明差异出现在哪个 ΔE 段。
- **阈值附近不可用区**：对方若有阈值律振荡（−d/2r²）图，其分项曲线在阈值以上约 0.5 eV 内不可用于比值。设成硬闸门并把被闸掉的点标 `--`，不要静默内插。
- **`\le` / `\ge` 在 matplotlib mathtext 报错**：用 `\leq` / `\geq`。
- **中文路径**：PowerShell `-File` 不可用 ⇒ Git Bash + 显式绝对路径的 python。
- **报告与表格必须同源**：先让分析脚本 dump JSON，导出脚本与绘图脚本只消费 JSON；禁止各自重算（否则必然漂移）。
- **★ 把 n 当证据数**：网格点数 ≠ 独立数据。密集网格 τ 可达数百 ⇒ 1911 点只值 20 个独立数。**先算 τ 与 neff 再算 CI**，否则一切精度声明虚高一个数量级以上。
- **★ 块自助块长不设上限**：`block = 3τ` 在强自相关下让块数跌到 3–4 ⇒ CI 退化（下界 > 中心）。**封顶 `n/8`**，并同时跑批均值法作主口径。
- **★ bootstrap p 撞地板**：所有格报同一个 `1/B`。**改用批均值 t 检验 p**，并注明 bootstrap p 的分辨率地限。
- **★ 用窄带数字对外**：带宽与阈值不确定度同量级时，带边界平移会把点搬进搬出，中心统计量摆动 20%+。**窄带只做定性判断，不出具体数字。**
- **★ 拿"无显著差异"当"等价"**：二者不同。必须三分门控（EQUIVALENT / SIGNIFICANT / INSUFFICIENT）。
- **★ 只读表格不读表注**：关键参数（阈值、基准量、被固定的量）常只写在 caption 里。血亏一次：阈值整组用错，全部比值偏。
- **★ 对方产物是闭式律时仍去比数据点**：比较域被人为限死在几个点上，且批判对象与致害对象不一致。**先找式子**（第 9 步）。
- **★ 只做一族参数就下结论**：头号数字可能在"原样默认 / 已发表定参 / 重拟合到标定点 / 精确穿过标定点"之间翻转数倍。**必须列变体族**；若答案不稳，另找独立可观测量判别。
- **★ 把对方"参数与其自身数据不符"直接当错误**：先查它拟合的是不是别的东西（如整段谱形状）。**拟合目标不同 ≠ 对方错误**。
- **★ 把倍数差异与形状差异混为一谈**：常数因子只动截距、动不了 log-log 斜率。斜率显著非零 ⇒ 是真形状分歧，不能再用"归一化/FC/比例常数"解释。
- **★★ 照抄 PDF 文本抽取出来的公式（丢上标/根号）**：抽取器会把上标压成控制字节（如 `\x02`）或干脆吞掉，于是 `(1−EA/ε)^{1/2}` 变成看起来无害的线性式。后果极端：把对方的**正常拟合**判成**系统性偏低数倍**，进而写出"它连自己的标定点都重现不了"这种会被反打的结论。**必须**用「作者自述的极限行为」+「单参数反演」双校验（第 9 步 第 0 条）。
- **★ 看到"残差全偏同一侧"不先怀疑自己**：正常最小二乘拟合的残差必须**符号混合**。若某个式推出对方所有标定点同号偏离，**第一嫌疑是自己的式子写错了**（指数、单位、变量定义），而不是对方造假。实战中这正是被用户一句"拟合怎么可能都偏小"当场击穿的。
- **★ 用变体数量冒充稳健性**：变体族只在"下游口径不明"时才需要；一旦能用独立可观测量锁定下游用的是哪一套，就**只比那一套**。滥用变体会把作者自己承认的"该式对本物种拟合不佳"包装成"对方数据有错"，是给审稿人递刀。
- **★★ 把"两份文档数字不一致"直接当成"请用户择一"**：先按 §8.8 查三件事——**同一批数据吗？同一个量吗？同一个估计方法吗？**。实战中两套"不确定度"的差异同时来自三个来源（旧网格数字过期 / `RMS 相对 1` 与 `GSD 绕均值` 是两个不同的量 / n = 6 百分位自助过窄），**查完问题自动消失**，根本不是选择题。抛回去只会浪费一轮。
- **★ 网格代次漂移**：项目里网格被加密后，旧文档的数字**不会**回溯更新。验证法：用**当前**网格做最近点取值再比对——吻合 4–5 位 ⇒ 该文档就是当前口径；系统性偏离 ⇒ 过期（本例 C₂H⁻@3.04：新 0.1512 vs 旧 0.134，差 11%）。
- **★ 判据线取单值**：把阈值当**区间**跑（如 2.83 / 3.13 / 3.21 三个候选估计量），若结论不变就在文中写出来 —— 一次性消灭"你凭什么取这个阈值"，且免去请用户裁定口径。
- **★★ 拿偏倚 GM 的数值直接断言"系统性大 N 倍"**：中心偏大 ≠ 系统偏大。必须过§8.11 四条件——**CI 排除 1 / 幅度连区间 / 逐点 >1 比例 / 聚合层级**。本例 C₂H⁻ 两个对照物下各 9.1% 与 2.4% 的点方向相反 ⇒ 该物种只能写方向，写"systematically 2×"会被驳。
- **★ 把"CI 排除 1"当成可池化的许可证**：可池化由**逐子群跨度**决定（<1.25× 才可给单一数字）。本例 ② 跨度 1.05× 可合并、③ 跨度 3.80× 禁合并——**跨度本身就是结论**。
- **★ 大样本 CI 拿 n 去读精度**：批均值口径下 `df = 批数 − 1`（本例 7 而非 2000），p 有 ~1e-3 地板，`p<1e-3` 一律写 `<1e-3`，且 p 小不代表效应大。
